# 赚钱项目：Zero-Capital AI Revenue OS

目标：**0 本金启动，先跑通第一笔真实收入，再把 30%–50% 的利润投入到获客、工具、自动化和产品化。**

> 不承诺“稳赚”。本仓库的目标是用可验证的小步实验，提高拿到收入的概率，并用数据决定是否扩大规模。

## 当前主线：AI 自动化体检 + 工作流蓝图 + 代搭建

面向小企业、个体经营者、独立顾问、内容创作者和小型电商，帮助他们找出最值得自动化的重复工作，并交付可以直接执行的方案。

### 为什么先做服务，不先做 SaaS

- 0 本金即可开始，不依赖付费 API、服务器或广告。
- 可以先卖结果，再根据真实客户需求开发软件。
- 每一次交付都可以沉淀为模板、脚本、案例和数字产品。
- 客户愿意继续付费时，再升级到自动化实施和维护。

## 首个可卖产品

**AI Automation Profit-Leak Audit**

客户提供：业务介绍、当前工作流程、常用工具、最耗时的重复任务。

我们交付：

1. 当前工作流梳理；
2. 5 个自动化机会，按收益 / 难度 / 风险排序；
3. 3 个可执行工作流蓝图；
4. 推荐工具与低成本替代方案；
5. 可直接复制使用的提示词、消息模板或 SOP；
6. 可选：付费代搭建其中一个自动化。

### 初始报价建议

| 套餐 | 内容 | 建议起步价 |
|---|---|---:|
| Starter | 业务体检 + 5 个机会点 + 优先级 | US$39 |
| Growth | Starter + 3 个详细工作流蓝图 + SOP / Prompt | US$99 |
| Build | Growth + 代搭建 1 个轻量自动化 | US$249 起 |

前 3–5 个客户可以用限量首发价换取案例和评价，但不要无限低价。

## AI 团队

- **AI 总监**：拆任务、分派、决定是否返工。
- **市场研究员**：识别客户行业、痛点、竞争方案和可行工具。
- **方案架构师**：设计自动化工作流、边界和失败兜底。
- **交付工程师**：生成最终报告、SOP、脚本、模板。
- **AI 审核员**：检查事实、可执行性、风险、过度承诺和遗漏。

详细指令见 `prompts/agent_team.md`。

## 执行规则

1. 不花钱买流量，直到至少有真实成交或明确转化数据。
2. 不开发客户没有付费意愿验证过的大功能。
3. 不使用虚假案例、虚假评价、垃圾群发或违规获客。
4. 每单记录：线索来源、报价、成交价、工时、交付问题、复购机会。
5. 每周只扩大有效渠道，砍掉没有反馈的动作。
