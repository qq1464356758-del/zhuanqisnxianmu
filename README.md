# 赚钱项目：国内 AI 项目孵化库

目标：**0 本金或极低成本启动，优先做中国境内可收款、客户不能靠打开一个通用 AI 就自行完成的项目。赚到真实利润后，将 30%–50% 用于扩大数据、部署、获客和产品化。**

> 不承诺稳赚。只做能被真实用户付费验证的项目，并用数据决定继续、改版或砍掉。

## 项目选择硬规则

以下项目直接淘汰：

- 纯文案、改写、翻译、PPT、普通表格、简历等通用 AI 可直接完成的工作；
- 单纯售卖 Prompt；
- 只靠“AI 生成内容”就能交付的服务；
- 需要先大量投广告、囤货或购买昂贵 API 才能验证的项目；
- 依赖违规爬虫、批量骚扰、账号矩阵作弊、平台漏洞的项目。

优先做同时具备 4 个条件的项目：

1. **持续数据**：需要每天/每小时更新的数据源；
2. **客户私有上下文**：要结合客户自己的资质、产品、规则、历史数据；
3. **自动执行**：不只“回答”，还要采集、去重、筛选、评分、通知、留痕；
4. **可复购**：客户停止付费后会失去持续价值，而不是一次生成后永久够用。

## 当前主线：垂直行业招投标 / 政府采购商机雷达

不是做一个“搜索招标信息的网站”，而是给某一个垂直行业的小企业做 **24 小时商机筛选系统**。

系统每天从公开、合法的数据源读取采购/招标/采购意向信息，与客户的：

- 经营范围
- 可供产品 / 服务
- 所在地区
- 企业资质
- 可承接预算
- 黑名单条件
- 历史中标 / 投标偏好

进行匹配，然后输出真正值得跟进的项目。

### 客户看到的结果

每条商机至少给出：

- 项目名称、采购单位、地区、预算；
- 报名 / 投标截止时间；
- 关键资格条件；
- 客户匹配分；
- 推荐理由；
- 不匹配 / 废标风险；
- 下一步要准备的材料；
- 原始公告链接。

### 为什么通用 AI 不能直接替代

通用 AI 可以解释一份招标公告，但不能天然完成：

`持续抓取 → 多源标准化 → 去重 → 企业资质匹配 → 风险规则 → 每日增量更新 → 截止时间提醒 → 历史反馈学习`

我们的产品价值在于整个系统和数据闭环，而不是某一次 AI 回答。

## 第一阶段验证行业

不要一开始做“全行业招投标平台”。先选一个公告多、客单价够高、供应商数量多的垂直领域做深。

候选优先级：

1. IT 运维 / 系统集成 / 弱电安防；
2. 办公设备 / 耗材 / 数码采购；
3. 广告印刷 / 标识制作 / 活动物料；
4. 实验室设备 / 仪器耗材；
5. 企业培训 / 会务 / 第三方服务。

最终根据真实公告数量、数据可获取性和潜在客户数量确定首个行业。

## 收费逻辑（验证版）

初期不开发复杂 SaaS，先卖“结果”：

- **体验版**：7 天精准商机日报，首批可免费/低价换真实反馈；
- **标准版**：¥99–299 / 月，按行业 + 地区推送；
- **专业版**：¥499–999 / 月，加入企业资质库、评分、截止提醒、材料清单；
- **企业定制**：数据源、私有规则、飞书/企微通知、多人协同，单独报价。

定价仅作为测试起点，以真实成交和续费数据调整。

## MVP 技术原则

第一版只做 5 件事：

1. 获取合法公开公告；
2. 统一字段并去重；
3. 规则 + AI 做匹配评分；
4. 输出每日精选商机；
5. 保存客户反馈用于改进。

不在 MVP 阶段做：复杂 CRM、全行业覆盖、大模型微调、原生 App、花哨 BI。

## AI 团队

- **AI 总监**：决定项目、拆任务、设置淘汰标准；
- **数据工程角色**：数据源接入、清洗、去重、字段标准化；
- **行业分析角色**：定义资质、关键词、排除词、风险条件；
- **产品工程角色**：搜索、评分、通知和用户反馈闭环；
- **AI 审核角色**：检查 hallucination、公告原文一致性和风险提示。

## 收入飞轮

`一个垂直行业 → 5 个试用客户 → 找到高价值筛选规则 → 第一个付费用户 → 月费续费 → 第二行业 → 自动化部署 → 利润再投资 30%–50%`
