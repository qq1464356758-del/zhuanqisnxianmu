# China DateOps — 首个自动技能实验规格

## 一句话价值

让 AI 在中国工作日、调休、补班和截止日期计算上给出**可验证、确定性、带数据版本**的结果，而不是凭语言模型猜日期。

## 目标用户

- HR / 行政 Agent
- 采购 / 招投标 Agent
- 客服 SLA Agent
- 项目管理 Agent
- 合同执行 / 运营排期 Agent（仅做日期计算，不提供法律判断）

## 核心函数

### is_workday(date)
返回：
- date
- is_workday
- type: normal_workday / weekend / statutory_holiday / makeup_workday
- holiday_name（如适用）
- data_version

### add_workdays(start_date, n, include_start=false)
支持正数/负数，返回最终日期和逐日跳过记录。

### count_workdays(start_date, end_date, inclusive="both")
明确包含边界口径。

### deadline_from_text(text, base_date)
解析类似：
- 3个工作日后
- 下一个工作日
- 本周最后一个工作日
- 2026-09-18起5个工作日

必须把自然语言转成结构化参数后再调用确定性计算函数。

### batch_calculate(items)
批量处理，避免用户一条条问。

## 数据层

`calendar/<year>.json`

示例字段：

```json
{
  "year": 2026,
  "source": "国务院办公厅关于2026年部分节假日安排的通知",
  "source_date": "2025-11-04",
  "holidays": [],
  "makeup_workdays": []
}
```

## 自动更新

每年 10~12 月由 Scout 检查国务院新年度节假日通知。

发现新通知后：
1. 提取放假日期；
2. 提取补班日期；
3. 生成下一年度 JSON；
4. 生成回归测试；
5. QA 与原公告逐条比对；
6. 人工只做最终一次确认；
7. 发布新技能版本。

## 自动测试

必须覆盖：
- 普通周一到周五；
- 普通周末；
- 法定节假日；
- 周六/周日补班；
- 节日前最后工作日；
- 节后第一个工作日；
- 跨年；
- n=0；
- 负向工作日；
- 包含/不包含起始日；
- 批量1000条日期计算。

## 禁止功能

- 不判断法律期限是否适用；
- 不承诺法院、税务、监管机关的具体期限解释；
- 不把「工作日计算」包装成法律意见；
- 无官方数据时不得猜测未来年度调休安排。

## 付费价值增强

如果单纯日历计算不足以通过付费技能审核，增加：

1. 批量 Excel / CSV 日期列处理；
2. 多种截止日口径；
3. 计算链路审计；
4. 年度数据自动更新；
5. REST/工作流友好的严格 JSON；
6. 时间窗口碰撞检测；
7. SLA 时间段计算（仅时间数学，不提供行业法律规则）。

## MVP 成功标准

不是先看收入。

1. AI 能自动生成技能文件包；
2. 100+ 回归用例全通过；
3. 无外部付费 API；
4. 能申请上架；
5. 付费审核通过；
6. 自然曝光产生至少 1 个真实购买/订阅。

只要第 5 步失败且整改后仍无法过审，就立刻把重点转向 `China RegionOps`，不恋战。
