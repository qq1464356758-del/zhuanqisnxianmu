# 招投标 / 政府采购商机雷达 MVP

## 产品一句话

每天自动从合法公开来源发现新增采购 / 招标信息，结合客户自己的业务范围和资质，筛出真正值得跟进的项目并提醒截止时间。

## 第一版用户

优先寻找 5–20 人的小型供应商 / 服务商，他们通常没有专职招投标信息团队，却需要持续找项目。

候选行业：

- IT 运维 / 系统集成 / 弱电安防；
- 办公设备 / 耗材；
- 广告印刷 / 标识 / 活动物料；
- 实验室设备 / 耗材。

## 数据源原则

只接入合法公开、允许访问的数据源；尊重 robots、网站条款、访问频率和接口规则。

第一批重点研究：

- 中国政府采购网公开公告与采购意向；
- 全国公共资源交易平台公开信息；
- 各省市公开采购 / 交易平台中可合法获取的页面或接口。

每条数据保存来源 URL 和抓取时间，AI 结论不得替代原始公告。

## 匹配评分 V0

总分 100：

- 行业 / 产品匹配：30
- 地区匹配：15
- 预算匹配：15
- 资格匹配：25
- 截止时间可操作性：10
- 历史偏好：5

任何明确不满足的硬性资格，必须标记为“高风险 / 不建议”，不能靠 AI 猜测资质。

## 每日输出示例

### 92 分｜建议立即跟进

**某市学校网络改造采购项目**

- 预算：¥680,000
- 地区：广东深圳
- 截止：2026-09-20 09:00
- 命中：网络改造、交换机、系统集成
- 资格：要求营业执照、相关履约能力；未发现当前客户明确缺失的硬性资质
- 风险：交付周期短，需要确认现货与施工人员
- 下一步：下载采购文件 → 确认品牌限制 → 复核类似业绩 → 建立投标任务
- 原文：保留官方链接

## MVP 页面

1. 今日商机
2. 项目详情
3. 客户规则配置
4. 已忽略 / 已跟进
5. 截止日历

## 验证方式

不要先收费做大系统。

### 第 1 阶段：数据可用性
连续抓取 3 天，确认：
- 每天有稳定新增公告；
- 字段能结构化；
- 去重有效；
- 关键截止时间可提取。

### 第 2 阶段：精准度
人工构造 3 个虚拟企业画像，每天检查 Top 20 推荐：
- Precision@20 目标 ≥ 70%；
- 硬资格错误推荐率 < 5%。

### 第 3 阶段：真人验证
找 5 个目标行业从业者体验 7 天，只问三件事：
- 是否发现过原本可能漏掉的项目？
- 每天是否节省至少 20–30 分钟？
- 如果保持这个精准度，是否愿意每月付 ¥99–299？

### 成功门槛
5 个体验用户中至少：
- 3 个连续使用 5 天以上；
- 2 个明确愿意付费；
- 1 个真实付款。

达不到则先调整行业 / 筛选规则，不继续堆功能。

## 技术路线（零成本优先）

第一版可使用：

- Python 数据采集与清洗；
- SQLite / JSON 保存 MVP 数据；
- 规则引擎优先，AI 用于公告语义分类和解释；
- 定时任务每日运行；
- 静态 / Serverless 页面展示；
- 飞书 / 企业微信 / 邮件通知按可用免费能力选择。

模型 API 不是第一天的必要条件：能用确定性规则解决的，不调用模型。

## 禁止功能

- 不提供围标、串标或规避监管功能；
- 不伪造资质、业绩、证书；
- 不替客户作法律意义上的投标承诺；
- 不把 AI 判断描述成官方结论；
- 不通过绕验证码、绕登录、攻击接口等方式取数据。

## 下一步开发顺序

1. 数据源探测器；
2. 公告解析器；
3. 去重器；
4. 企业画像与规则评分；
5. 每日 Top N 报告；
6. 再决定是否做 Web UI 和自动通知。
