# Offer v1：AI Automation Profit-Leak Audit

## 一句话定位

帮助小企业和个体经营者在不先购买昂贵软件的情况下，找出最值得自动化的重复工作，并拿到可执行的工作流蓝图。

## 理想客户

优先：

- 1–20 人的小型服务企业；
- 独立顾问 / 教练 / 代理商；
- 小型电商和内容团队；
- 每周有 5 小时以上重复行政、跟进、内容或数据工作的人。

暂不优先：

- 需要企业级安全审计或复杂合规的公司；
- 需求模糊但要求“全自动赚钱”的客户；
- 需要大量付费 API 才能验证价值的项目；
- 高风险金融、医疗、法律决策自动化。

## 客户买到的不是“AI”，而是三个结果

1. **时间**：减少重复劳动；
2. **速度**：缩短线索响应、内容生产或资料处理时间；
3. **可控性**：知道哪些步骤可以自动、哪些必须人工审核。

## 套餐

### Starter — US$39

- 客户现状梳理；
- 5 个自动化机会；
- 收益 / 难度 / 风险评分；
- 推荐第一个应做的工作流；
- 3 页左右的精简报告。

### Growth — US$99

包含 Starter，另加：

- 3 个详细工作流蓝图；
- 每个工作流的触发、输入、处理、输出、失败兜底；
- 推荐工具与免费 / 低成本替代方案；
- 可复制 Prompt / SOP / 消息模板；
- 实施顺序和预计维护点。

### Build — US$249 起

包含 Growth，并代搭建一个轻量自动化。默认只使用客户已经拥有的账号、免费额度或客户自行承担的第三方费用。

## 首批验证策略

- 前 3–5 单允许用限量首发价，但必须明确原价；
- 不以“保证增收”作为卖点；
- 卖点改为：减少重复工作、缩短响应时间、降低漏单和遗漏；
- 每单结束收集：实施前耗时、实施后耗时、客户主观满意度、是否愿意继续购买。

## 最小交付流程

1. 客户填写 `templates/client_intake.md`；
2. AI 总监检查信息是否足够；
3. 市场研究员识别行业痛点和常见工作流；
4. 方案架构师设计 5 个机会并选 Top 3；
5. 交付工程师写报告；
6. AI 审核员进行事实、可执行性和风险检查；
7. 最终交付；
8. 询问是否需要 Build 套餐。

## 成功标准

首阶段只看四个指标：

- 20 个精准触达能否产生至少 1 个有效对话；
- 10 个有效对话能否产生至少 1 个付费客户；
- 一单 Growth 的总交付时间能否压到 90 分钟以内；
- 客户是否愿意购买实施、维护或第二个工作流。

如果连续两个验证周期都没有付费信号，优先换细分行业或卖点，而不是继续开发功能。
