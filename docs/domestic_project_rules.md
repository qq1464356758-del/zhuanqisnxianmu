# 国内赚钱项目选择规则

## 核心判断

一个项目如果客户只需要把需求复制到 DeepSeek / 豆包 / Kimi / ChatGPT，然后几分钟内得到可用结果，就不做。

真正值得做的项目，需要至少包含以下两层以上的“AI 外部能力”：

- 实时 / 持续数据源；
- 客户私有数据或知识库；
- 自动化执行；
- 多系统集成；
- 权限、部署、通知；
- 行业规则和结构化校验；
- 长期运行和维护。

## 评分表

每个候选项目按 0–5 分评价：

| 指标 | 说明 |
|---|---|
| AI 不可直接替代 | 通用聊天 AI 能否独立完成 |
| 付费刚需 | 不解决是否会损失时间、钱或机会 |
| 持续性 | 是否有月费/续费可能 |
| 0 成本可验证 | 是否能先用免费资源做 MVP |
| 可自动化 | 后续是否能降低人工边际成本 |
| 国内收款方便 | 微信/支付宝/平台交易是否可行 |
| 合规性 | 是否依赖违规采集、骚扰营销等 |

总分低于 24/35：原则上不进入开发。

## 明确不做

- AI 写稿代写；
- AI PPT；
- 普通 Excel / 表格处理；
- 简历优化；
- Prompt 售卖；
- 普通图片生成；
- AI 摘要 / 翻译；
- 批量洗稿、伪原创；
- 群发获客机器人；
- 绕过平台风控的自动化工具。

## 优先方向

### A. 垂直商机监控
持续采集公开信息，并结合客户条件过滤、评分、提醒。

### B. 垂直合规 / 文件审查
不是“让 AI 看文件”，而是结合行业规则库、企业模板、强制校验、版本追踪和人工复核。

### C. 企业内部数字员工
把 AI 接入企业自己的文档、表单、审批、通知、CRM 等系统，执行完整流程。

### D. 数据变化监控
价格、政策、招标、竞争产品、库存、渠道等发生变化时自动识别并通知。

## 当前第一名

**垂直行业招投标 / 政府采购商机雷达。**

原因：公开数据丰富、结果价值明确、漏掉一次项目可能意味着真实收入损失，同时天然适合订阅制。
